# Security Policy

## Supported Versions

Security updates and patches are provided for the current active release line of RacePulsePH:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, report suspected vulnerabilities privately using one of the following channels:

1. **GitHub Security Advisories (preferred):** Submit a private report at [github.com/2001105254-netizen/RacePulsePH/security/advisories/new](https://github.com/2001105254-netizen/RacePulsePH/security/advisories/new).
2. **Email:** Send details to `events@racepulseph.com` with `[SECURITY]` in the subject line.

### What to Include

To help us reproduce and resolve the issue quickly, please include:

- A clear description of the vulnerability and its potential impact.
- Affected URLs, endpoints, Cloud Functions, Firestore/Storage rules, or source files.
- Step-by-step instructions or a minimal proof of concept to reproduce the issue.

### What to Expect

- **Acknowledgement:** You will receive an initial response within 48 hours confirming receipt of your report.
- **Updates:** We will provide status updates at least once every 7 days while the report is being investigated and remediated.
- **Accepted Reports:** Once verified, we will develop and deploy a fix, notify you when the patch is live, and coordinate public disclosure (with credit if you wish).
- **Declined Reports:** If a report is out of scope, cannot be reproduced, or does not pose a security risk, we will reply with a clear explanation of the decision.
