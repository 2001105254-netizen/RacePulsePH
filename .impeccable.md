## Design Context

### Users
RacePulsePH runners creating accounts, registering for races and recovering account access, and organizers managing race events.

### Brand Personality
Athletic, welcoming, precise. Account messages should inspire confidence and retain the community voice requested by the creator: “Happy running ka Racepulse!”

### Aesthetic Direction
The creator requested an aesthetic, professional design consistent with the existing app. Preserve the RacePulse logo, charcoal brand header, system red accent, rounded controls and light/dark surfaces. Email uses a restrained light reading area, charcoal logo header and large red verification code.

### Design Principles
- Make the next account action clear and accessible on mobile.
- Give the code strong visual priority, with expiry and resend guidance nearby.
- Use the existing RacePulse assets and design tokens for continuity.
- Keep security explanations concise and friendly.
