# ISO 11064-4: Ergonomic Design of Control Centres (Workstation Layout & Sightlines)

## Standard Identity & Scope

- **Designation:** ISO 11064-4 (Ergonomic design of control centres, Part 4: Layout and dimensions of workstations).
- **Scope:** Ergonomic requirements and anthropometric layout principles for control-room workstations, governing visual sightlines, display arrangement, primary vs secondary reach zones, and multi-task console geometry.

## Core Principles Audited by This Skill

1. **Primary sightline preservation:** Place high-frequency monitoring data and active event queues inside the primary visual zone so operators keep eyes on live state without turning, scrolling, or window switching.
2. **Single-viewport console lock (`100vh`):** Eliminate body-level vertical page scrolling and marketing footers on operator consoles so the entire control surface fits within one stable frame (`1080p` and `1366x768`).
3. **Functional zone allocation (`64%` / `36%` split):** Dedicate the wider primary zone (`64%` left) to live situational displays/tables and anchor interactive command/hardware/scanner consoles in an adjacent reach dock (`36%` right).
4. **Full-bleed horizontal utilization:** Eliminate artificial narrow column wrappers (`max-w-*` dead zones) on widescreen control monitors so horizontal display real estate carries real telemetry instead of blank margins.

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Viewport lock (`lg:h-screen lg:overflow-hidden`):** The outer shell uses `flex flex-col lg:h-screen lg:overflow-hidden`, allocating fixed vertical height to the top header (`<= 52px`) and telemetry ribbon (`<= 40px`) and giving `flex-1 min-h-0` to the split workspace.
- **No footers in operator mode:** Remove marketing link blocks, copyright footers, and decorative padding below the workspace fold (`AGENTS.md` / `R-05`).
- **Simultaneous visibility at `1366x768`:** Verify the `64%` / `36%` split does not collapse or clip action buttons on compact `1366x768` timing laptops (`lg:` breakpoint at `1024px+`).

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Viewport-adapted zone priority:** On handhelds (`< 1024px`), linearize the workstation into one vertical observation stream (`flex-col min-h-[100dvh]`) and relocate the desktop `36%` action zone into the ergonomic lower thumb arc (`bottom-0`) plus on-demand bottom sheets.
- **Minimum top chrome (`48px`):** Prevent sticky headers and filter blocks from consuming the upper viewing zone (`<= 15%` of `844px` height).

## Inspection Evidence

- Measure `document.documentElement.scrollHeight <= window.innerHeight` at `1366x768` and `1920x1080` on the desktop console route.
- Confirm zero blank side gutters (`max-w-*` lateral dead zones) on widescreen monitors.
- Verify left/right split proportions (`~64%` / `~36%`) leave every button and readout unclipped at `1366x768`.
