# ISO 11064-5: Ergonomic Design of Control Centres (Displays & Controls)

## Standard Identity & Scope

- **Designation:** ISO 11064-5 (Ergonomic design of control centres, Part 5: Displays and controls).
- **Scope:** Design and co-location of visual displays (screens, indicator lamps, mimic readouts, alarms) and operator controls (buttons, triggers, hardware inputs) to maximize safety, speed, and error-free human-system operation.

## Core Principles Audited by This Skill

1. **Co-location of controls and displays:** Keep hardware/scanner triggers, chip assignment inputs, and state-transition controls directly alongside the live feed they affect rather than splitting them across separate pages or tabs.
2. **Strict separation of read-only telemetry vs editable controls:** Operators must distinguish passive status displays (`LAN Connected`, `Elapsed Clock`, `Finisher Count`, `Offline Queue`) from mutable configuration inputs (`Gun Start Override`, `Reader Port`, `Penalty Seconds`) at a glance.
3. **Clear alarm & connectivity priority:** Degraded states (`LAN Offline`, `Pending Offline Queue > 0`, `Duplicate Read`) must surface as persistent, unmistakable visual status cues without blocking active local controls (`R-27`).
4. **Low-latency trigger mapping:** High-frequency operational actions use direct single-click buttons or hardware F-key bindings rather than multi-step dropdowns.

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Telemetry ribbon boundary (`<= 40px`):** Keep the top telemetry strip strictly read-only (`tabular-nums` counts, clock, LAN/bridge status). Never embed text fields, `<select>` config inputs, or action buttons inside passive KPI cells.
- **Persistent right control dock (`36%`):** House hardware status controls, QR/RFID scan triggers, manual bib entry, and editable settings in the dedicated right-hand dock, clearly visually bounded from the left live table (`64%`).
- **Explicit F-key accelerators:** Bind primary operator commands (`F1` Primary Scan/Check-In, `F2` Copy/Assign, `F3` Sync/Refresh, `F4` Export, `Ctrl+F` Search, `Space` Trigger/Pause when safe) with visible keycap badges.

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Separate status drawer from action dock:** Read-only telemetry expands from the `48px` top bar; primary interactive triggers stay anchored in the `bottom-0` thumb dock.
- **Editable form isolation:** Open editable parameters (chip assignment, manual split edit, checkpoint config) inside a dedicated bottom-sheet dialog so field staff cannot accidentally edit configuration while scrolling the runner list.

## Inspection Evidence

- Audit every metric cell in the telemetry strip to confirm zero `<input>`, `<select>`, or mutable buttons sit inside read-only display chips.
- Verify hardware controls, scanners, and forms reside in the right `36%` dock on desktop and in a bottom sheet / bottom bar on mobile.
- Test keyboard triggers (`F1`-`F4`, `Ctrl+F`, `Space`) and verify live feedback updates immediately on action.
