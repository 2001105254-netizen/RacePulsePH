# ISO 9241-115: Conceptual Design & Navigation

## Standard Identity & Scope

- **Designation:** ISO 9241-115 (Ergonomics of human-system interaction, Part 115: Guidance on conceptual design, user-system interaction design, user interface design and navigation design).
- **Scope:** Structuring the conceptual model, information architecture, windowing/view splitting, and navigation topology so users move cleanly between tasks without intermediate dead-end hubs.

## Core Principles Audited by This Skill

1. **Direct conceptual mapping:** Screen regions must match the operator's mental model (e.g., Event Context -> Live Runner Queue -> Field/Hardware Action Dock) instead of arbitrary grid mosaics.
2. **Shallow navigation depth:** Replace intermediate landing galleries, redundant "select a module card" detours, and nested sub-dashboards with persistent inline context switchers and direct view splitting.
3. **Windowing & simultaneous view splitting:** Keep related reference data and action panels visible side-by-side on large viewports rather than forcing tab-hopping or full-page route transitions that break context.
4. **Visible navigation state:** Show the active module breadcrumb, current event scope, and mode switch in one predictable, persistent location (`R-24`).

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Consolidated header (`<= 52px`):** Merge brand mark, active module breadcrumb, global event/race `<select>` switcher, and primary toolbar CTAs into one compact top bar.
- **Inline context switching:** Switching the active race event, checkpoint, or filter view must update the split workspace inline without bouncing the operator back to a card selection gallery.
- **Persistent master-detail split:** Display the item directory/queue on the left (`64%`) and the active inspector, scanner, or configuration dock on the right (`36%`) so selection and action share one frame.

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Single-row sticky context bar (`48px`):** Compress the module title, active event selector trigger, and telemetry drawer toggle into a single sticky header so content starts immediately at `y = 48px`.
- **On-demand detail sheet instead of route loss:** Tapping a runner card or primary tool (`Assign Chip`, `Filters`, `Telemetry`) opens a swipeable or dismissible bottom sheet over the list rather than navigating away and losing scroll position.
- **Predictable back/dismiss paths:** Every sheet and modal closes cleanly via backdrop tap, explicit Close button, or `Escape` (`R-32`).


## Inspection Evidence

- Measure header height in rendered DOM (`<= 52px` desktop, `48px` mobile sticky bar) and verify zero intermediate card-gallery screens block direct access to the active queue.
- Confirm every navbar/switcher destination resolves to a live view (`R-24`, `R-26`).
- Verify mobile drawer/sheet dismissal restores the exact scroll position of the underlying runner list.
