# ISO 9241-920: Guidance on Tactile and Haptic Interactions

## Standard Identity & Scope

- **Designation:** ISO 9241-920 (Ergonomics of human-system interaction, Part 920: Guidance on tactile and haptic interactions).
- **Scope:** Ergonomic requirements and guidance for touch, tactile, and haptic interactions, addressing physical reachability, touch target geometry, inter-target separation, and clear tactile/visual actuation feedback.

## Core Principles Audited by This Skill

1. **Thumb-zone ergonomics (Bottom `30%` Arc):** On handheld screens (`390x844`), place the highest-frequency primary actions inside the natural single-handed thumb reach zone (`bottom-0` sticky dock) rather than top-left or top-right corners.
2. **Minimum touch target geometry (`>= 44x44px` / `h-11`):** Every tappable button, filter pill, checkbox wrapper, tab, and row action on touch viewports must measure at least `44x44px` (`min-h-11 min-w-11`) to avoid miskeys while moving or wearing gloves outdoors (`R-03`).
3. **Adequate inter-target spacing (`>= 8px` gap):** Separate adjacent touch controls by at least `8px` (`gap-2`) so fat-finger taps never trigger neighboring destructive or wrong-row actions.
4. **Immediate actuation feedback:** Provide deterministic press feedback (`active:scale-[0.98]` under `150ms`, disabled loading states, and clear state confirmation via `FeedbackProvider`) while respecting `prefers-reduced-motion`.

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Pointer + touch hybrid readiness:** Even on `1366x768` timing laptops that may feature touchscreens, keep primary action buttons comfortably clickable (`>= 36px` compact desktop toolbar controls, `>= 44px` primary commit buttons) with `>= 8px` spacing around destructive triggers.
- **Zero cramped icon clusters:** Avoid tightly packed `24px` icon rows without padding.

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Sticky bottom action bar (`bottom-0`):** Anchor primary tasks (`Scan Race Bib QR`, `Check In`, `Assign Chip`) inside a persistent bottom bar with safe-area padding (`pb-[max(0.75rem,env(safe-area-inset-bottom))]`).
- **Scroll clearance (`pb-24`):** Ensure the runner list and card container include enough bottom padding so the sticky action bar never covers the final card's tap target (`racepulse-launch-ux-states`).
- **Single-column touch flow:** Keep card rows full-width with one obvious primary tap area (`min-h-11`) on Line 2 (`One-Tap Action`).
