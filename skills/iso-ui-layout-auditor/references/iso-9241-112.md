# ISO 9241-112: Principles for the Presentation of Information

## Standard Identity & Scope

- **Designation:** ISO 9241-112 (Ergonomics of human-system interaction, Part 112: Principles for the presentation of information).
- **Scope:** Modality-independent principles ensuring presented information is detectable, distinguishable, clear, concise, consistent, and legible across visual and auxiliary displays.

## Core Principles Audited by This Skill

1. **Detectability:** Critical statuses, live connectivity indicators, and active timing counters must stand out immediately without hunting through decorative chrome.
2. **Discriminability:** Adjacent states (`Paid` vs `Pending`, `Finished` vs `DNF`, `Online` vs `Offline`, `Read-Only Telemetry` vs `Editable Input`) must differ clearly through shape, label, and contrast rather than subtle hue shifts alone.
3. **Clarity & Conciseness:** Eliminate verbose welcome paragraphs, marketing hero banners inside operational consoles, redundant multi-line card headers, and eyebrow capsule badges (`AGENTS.md` Hard Gate).
4. **Consistency:** Use uniform number formatting, timestamps, badge semantics, and unit placements across every row, telemetry strip, and modal.
5. **Legibility:** Enforce high contrast and `tabular-nums` alignment for all live clocks, bib numbers, split times, counts, and currency values so digits never jitter horizontally as values update.

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Zero decorative welcome banners:** Strip greeting cards, explanatory prose blocks, and multi-tier headers that push operational data down the screen.
- **High-density telemetry ribbon (`<= 40px`):** Replace oversized KPI hero tiles with a single horizontal readout strip using `tabular-nums` (`font-mono tabular-nums` or `font-sans tabular-nums`) for aligned counts and clocks.
- **Strict column scanability:** Right-align numeric metrics, timestamps, and currency columns; left-align runner names and categories; truncate overflowing secondary strings with accessible full titles (`title` or expandable detail).

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Outdoor sunlight contrast:** Enforce strong foreground-to-surface contrast (targeting WCAG AAA `7:1` where feasible for critical field status labels and primary action text, and strictly at least WCAG AA `4.5:1` / `3:1` large text per `R-25`).
- **2-line hybrid card legibility:** Restrict each row card to high-signal fields:
  - Line 1: `Bib #` (`tabular-nums font-semibold`) + `Runner Name` + `Status Badge`
  - Line 2: `Category` + `Official Time` (`tabular-nums`) + `One-Tap Action`
- **No color-only status encoding:** Pair semantic color fills/borders with explicit text labels or distinct icons (`R-39`).

## React & Tailwind Audit Patterns

```tsx
// Telemetry readout cell: tabular alignment + concise label + explicit contrast
<div className="flex items-center gap-2 px-3 py-1 border-r border-[var(--border-default)]">
  <span className="text-xs font-normal text-[var(--text-secondary)]">Checked In</span>
  <span className="text-sm font-semibold font-mono tabular-nums text-[var(--text-primary)]">
    {checkedInCount} / {totalCount}
  </span>
</div>
```

## Inspection Evidence

- Measure text and badge foreground/background contrast ratios across light and dark modes (using `antislop-human/contrast-check.py` or inspected tokens) to confirm `>= 4.5:1` normal / `>= 7:1` outdoor critical targets (`R-25`, `R-34`).
- Inspect numeric columns, live timers, and KPI strip values for `tabular-nums` classes (`font-mono tabular-nums` or `tabular-nums`).
- Confirm zero decorative hero banners, eyebrow pills, or redundant section titles remain inside the operational viewport.
