# ISO 9241-125: Visual Presentation of Information

## Standard Identity & Scope

- **Designation:** ISO 9241-125 (Ergonomics of human-system interaction, Part 125: Guidance on visual presentation of information; 2017 edition).
- **Scope:** Visual organization, syntactic and semantic coding, spatial grouping, visual density, and tabular alignment designed around human visual perception and working-memory constraints.

## Core Principles Audited by This Skill

1. **Spatial grouping (proximity & enclosure):** Group related metrics, fields, and triggers tightly with consistent structural spacing (divisible by `4px` / `8px` per `AGENTS.md`), and separate unrelated zones with crisp `1px` borders or clear gutters rather than nested heavy shadows.
2. **Optimal visual density:** Avoid both sparse whitespace bloat (oversized padding, giant empty card margins, narrow centered `max-w-*` cages on widescreens) and unspaced text walls.
3. **Tabular alignment & grid discipline:** Align headers, columns, labels, and numerical readouts cleanly along shared vertical axes so eye saccades scan top-to-bottom in one pass.
4. **Syntactic & semantic coding consistency:** Use consistent typography weights (`font-semibold` for headings/primary identifiers, `font-normal` for body/labels per `AGENTS.md`) and restrained OKLCH color accents (`60/30/10` budget).

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Lateral dead-zone elimination:** Remove narrow `max-w-4xl` / `max-w-5xl` centered containers on operator consoles; span `w-full` (`100%` viewport width) so tables show full columns without horizontal truncation or squished badges.
- **High-density data grid rows:** Use compact vertical padding (`py-2` / `36px-44px` row height on desktop pointer UIs) with `1px` hairline row dividers instead of stacked padded cards with `gap-6` margins.
- **Collapsed KPI strip (`<= 40px`):** Present all summary counts inline along one compact horizontal band instead of a multi-row grid of oversized stat cards.

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Single-column card-row hybrid:** Never squeeze a 6-to-8 column desktop table onto a `390px` screen with horizontal scroll; transform rows into predictable 2-line hybrid cards spanning `100%` width minus `12px`/`16px` outer gutter.
- **Collapsed summary drawer:** Fold multi-item telemetry ribbons into an expandable header drawer so the runner list receives maximum vertical viewport budget above the thumb bar.
- **Strict 4px/8px rhythm:** Keep inner card padding `12px` (`p-3`) and card-to-card spacing `8px` (`gap-2`) to preserve scan speed without crowding touch targets.

## React & Tailwind Audit Patterns

```tsx
// Full-width desktop table row vs mobile 2-line hybrid card
<table className="hidden lg:table w-full text-left border-collapse">
  <thead className="sticky top-0 z-10 bg-[var(--surface-card)] border-b border-[var(--border-default)] text-xs font-semibold">
    <tr>
      <th className="py-2 px-3 w-20">Bib</th>
      <th className="py-2 px-3">Runner</th>
      <th className="py-2 px-3">Category</th>
      <th className="py-2 px-3 text-right">Official Time</th>
      <th className="py-2 px-3 w-28 text-right">Status</th>
    </tr>
  </thead>
  <tbody className="divide-y divide-[var(--border-default)] text-sm">
    {rows.map((r) => (
      <tr key={r.id} className="hover:bg-[var(--surface-card)]/60">
        <td className="py-2 px-3 font-mono tabular-nums font-semibold">{r.bib}</td>
        <td className="py-2 px-3 font-semibold">{r.name}</td>
        <td className="py-2 px-3 text-[var(--text-secondary)]">{r.category}</td>
        <td className="py-2 px-3 text-right font-mono tabular-nums">{r.officialTime}</td>
        <td className="py-2 px-3 text-right">{r.statusBadge}</td>
      </tr>
    ))}
  </tbody>
</table>
```

## Inspection Evidence

- Inspect container classes for dead-zone width caps (`max-w-3xl`, `max-w-5xl`, `max-w-7xl` when full-bleed `w-full` console is required) at `1366x768` and `1920x1080`.
- Verify all padding/margin/gap utilities conform to `4px` / `8px` increments (`AGENTS.md`).
- Confirm zero horizontal overflow (`document.documentElement.scrollWidth <= window.innerWidth`) at `390x844` and `1366x768` (`R-03`).
