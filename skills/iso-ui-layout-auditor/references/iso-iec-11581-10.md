# ISO/IEC 11581-10: User Interface Icons (Framework & General Guidance)

## Standard Identity & Scope

- **Designation:** ISO/IEC 11581-10 (Information technology, User interface icons, Part 10: Framework and general guidance).
- **Scope:** Framework and design guidance for user interface icons covering symbol discriminability, semantic mapping, consistency, and preventing icon ambiguity across applications.

## Core Principles Audited by This Skill

1. **Zero duplicate icons across distinct navigation modules:** Every distinct navigation destination or operational tool must carry a unique, semantically distinct icon (or text-only tab) so users never confuse modules by scanning glyphs.
2. **Mandatory text labels or accessible tooltips:** Never ship unlabeled, mystery-meat icon buttons in consoles or mobile toolbars; attach visible concise text labels wherever space allows, and always include `aria-label` plus accessible tooltip/title on icon-only controls (`R-39`).
3. **Semantic relevance over decorative trend icons:** Reject generic placeholder glyphs (Sparkle, Magic, Robot, decorative lightning bolts) in favor of symbols directly matching the domain operation (`QrCode`, `Timer`, `Wifi`, `CheckCircle2`, `Ban` per `R-04`).
4. **Visual balance & consistent stroke weight:** Icons paired with text must stay aligned to the baseline (`inline-flex items-center gap-2`) and carry `aria-hidden="true"` when decorative alongside a visible label (`R-39`).

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Sidebar & toolbar icon uniqueness:** Audit all icons in `DesktopSidebar.tsx`, workspace tabs, and right-dock headers to verify zero glyph reuse across distinct destinations (`Timing`, `Events`, `Broadcast`, `Access`, `Bib Studio`).
- **Label + icon pairing:** Sidebar items and primary toolbar CTAs always render icon + text label (`1` to `2` words) plus optional shortcut badge; icon-only compact controls (`Refresh`, `Fullscreen`, `Close`) must declare `aria-label` and `title`.

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Labeled bottom navigation & action dock:** Every item in the mobile `BottomNav` or bottom action bar displays both a distinct icon and a short text label (`>= 11px-12px` readable label), never raw unlabeled icons.
- **No duplicate icons across bottom tabs and row actions:** Ensure row quick-actions (e.g., `Edit`, `Assign Chip`, `Verify`) use icons distinct from primary tab navigation icons.

## Inspection Evidence

- List every navigation module and toolbar button in the audited UI with its icon component name; confirm zero duplicate icon components map to different actions/modules.
- Confirm every icon-only `<button>` has a non-empty `aria-label` and accessible tooltip/title, and every icon paired with text sets `aria-hidden="true"` (`R-39`).
