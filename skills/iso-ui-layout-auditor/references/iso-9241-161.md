# ISO 9241-161: Visual User-Interface Elements

## Standard Identity & Scope

- **Designation:** ISO 9241-161 (Ergonomics of human-system interaction, Part 161: Visual user-interface elements; Second edition 2025).
- **Scope:** Requirements and recommendations governing when and how standard GUI elements (toolbars, sticky headers, split panes, filter controls, buttons, list boxes, modal dialogs, status indicators) are selected and operated.

## Core Principles Audited by This Skill

1. **Element-to-task fit:** Select native semantic controls (`<button>`, `<a href>`, `<select>`, `<input>`, `<table>`) matched to the interaction type rather than clickable `<div>` elements or decorative wrappers (`R-39`).
2. **Persistent command & context elements:** Keep primary toolbars, search inputs, filter pills, and table column headers sticky (`sticky top-0`) while scrolling long datasets so context never scrolls off-screen.
3. **Standardized split-pane & dialog behavior:** Master-detail panes must scroll independently (`min-h-0 overflow-y-auto`), and dialogs/drawers must trap or manage focus cleanly, dismiss on `Escape`, and escape clipped parent stacking contexts via portals (`DialogSurface`).
4. **Clear visual state affordances:** Interactive elements must exhibit unmistakable default, hover, active, disabled, and `:focus-visible` states plus `cursor: pointer` / `cursor: not-allowed` (`R-32`, `R-39`).

## Desktop Console Criteria (`1080p` / `1366x768`, `100vh`)

- **Sticky table headers (`<thead class="sticky top-0">`):** Column headers remain locked at the top of the left `64%` scroll container (`flex-1 min-h-0 overflow-y-auto`) while scrolling hundreds of runners.
- **Filter pill & search toolbar:** Keep filter chips and search input pinned immediately above the master list inside the left pane so filtering never shifts the right-hand control dock.
- **Portaled modal dialogs:** Render blocking confirmations and overlays through `src/components/ui/DialogSurface.tsx` (`document.body` portal) so `overflow-hidden` split panes never clip dialogs.

## Mobile Field-Staff Criteria (`390x844`, `100dvh`)

- **Sticky bottom command bar (`bottom-0`):** Anchor primary actions in a persistent footer with sufficient bottom padding (`pb-24`) on the main scroll area so the final card row is never obscured (`racepulse-launch-ux-states`).
- **Scrollable filter strip:** Render filter pills in a clean horizontally scrollable row (`overflow-x-auto`) with `min-h-11` (`44px`) hit areas instead of wrapping into a 3-row block that steals vertical space.
- **Bottom-sheet modal ergonomics:** Convert desktop right-dock tools into modal bottom sheets with explicit close buttons and `Escape` support.

## Inspection Evidence

- Verify `min-h-0` is applied on flex/grid scroll containers inside `lg:h-screen lg:overflow-hidden` so inner panes scroll without overflowing the `<body>`.
- Verify `<thead class="sticky top-0">` stays pinned when scrolling the left master table.
- Verify every button, tab, filter pill, and `<select>` shows visible `:focus-visible` outlines and works via keyboard (`R-32`, `R-39`).
