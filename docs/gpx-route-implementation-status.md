## Purpose decisions

- Dedicated `/routes` catalog and `/races/:raceId/routes/:distanceId` course pages provide shareable preparation URLs without exposing admin drafts, and unseeded runs filter strictly to existing Firestore races so unlinked demo presets never appear in production.
- Dual trail capture gives organizers both a stationary-drift/spike-filtered GNSS breadcrumb workflow (`Option 1`) and a zero-friction pointer-drag paintbrush + surface/terrain toolkit (`Option 2`) without leaving Route Studio.
- Synchronous local WGS84 graticule initialization avoids blank canvas flashes while OpenFreeMap styles stream in and preserves legibility offline.
- Segment discontinuities and missing GPX elevation spans remain explicitly represented rather than interpolated or straight-line bridged.
- Canonical geometry edits create draft revisions rather than mutating immutable preset versions or live race publications.
- Compound permission checks (`permBase`) in `firestore.rules` keep Firestore CEL rule evaluation under the 1,000-expression limit as permissions expand.
